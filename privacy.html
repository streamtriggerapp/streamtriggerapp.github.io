Privacy Policy

Last updated: 2026

1. Introduction

StreamTrigger is a desktop application designed to help streamers interact with TikTok LIVE sessions. This Privacy Policy explains how we handle data when using the application.

2. Information We Process

The application may process publicly available TikTok LIVE interaction data, including:

  • Usernames
  • Chat messages
  • Likes
  • Gifts and virtual items
  • Follows
  • Viewer engagement events

3. How We Use the Data

This data is used exclusively to provide features such as:

  • Points and ranking systems
  • Live interaction tracking
  • Alerts and notifications
  • Automation tools for streamers

4. Data Storage

StreamTrigger may store limited interaction data locally on the user's device to enable features such as points tracking and rankings. No sensitive personal data is stored.

5. Data Sharing

We do not sell, trade, or share personal data with third parties. All data processed is used only within the application.

6. Third-Party Services

StreamTrigger interacts with TikTok LIVE public data streams. This application is not affiliated with or endorsed by TikTok.

7. Security

We take reasonable measures to ensure that processed data is handled securely within the application.

8. User Responsibility

Users are responsible for ensuring they comply with TikTok's terms and policies when using the application.

9. Changes to this Policy

We may update this Privacy Policy from time to time. Updates will be reflected on this page.

10. Contact
