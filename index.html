StreamTrigger

StreamTrigger is a desktop application that helps streamers manage TikTok LIVE interactions and trigger real-time actions based on viewer activity.

TikTok Login is used to let creators connect their TikTok account before using StreamTrigger features.

What is StreamTrigger?

StreamTrigger connects to TikTok LIVE sessions and listens for real-time viewer events such as likes, gifts, chat messages, follows, and other live interactions. Streamers can use these events to power points, rankings, alerts, sounds, overlays, webhooks, and automation tools.

Live Event Detection

Receive TikTok LIVE events in real time, including likes, gifts, chat messages, follows, and viewer interactions.

Points & Ranking System

Reward viewers automatically with points, levels, and rankings based on their engagement during live sessions.

Automation Tools

Trigger sounds, overlays, AutoHotkey actions, webhooks, and other streamer tools from live events.

Desktop Control Panel

Manage live activity, diagnostics, rankings, settings, integrations, and event triggers from one app.

How It Works

  1. The streamer opens the StreamTrigger desktop application.
  2. The streamer connects a TikTok LIVE username.
  3. StreamTrigger receives live events in real time.
  4. The app processes events such as likes, gifts, chat, and follows.
  5. Configured actions are triggered automatically inside the desktop app.

Connect with TikTok

StreamTrigger uses TikTok Login so creators can connect their TikTok account and authorize supported TikTok features before using the desktop application.

The login process starts from the StreamTrigger desktop app and is used only to connect the creator’s TikTok account for streamer-facing tools such as LIVE interaction processing, alerts, points, rankings, and automation.

Use Case

StreamTrigger is designed for streamers who want to increase live engagement by turning viewer activity into interactive rewards and automation. For example, viewers can earn points when they like, comment, follow, or send gifts during a TikTok LIVE session.

Platform

StreamTrigger is currently a desktop application. It is intended for creators and streamers who manage live sessions from a computer.

Data & Privacy

StreamTrigger uses TikTok LIVE interaction data only to provide streamer-facing features such as live activity, points, rankings, alerts, and automation. The app does not sell personal data.

The application may process public live interaction data such as usernames, chat messages, likes, gifts, and follows during a live session in order to provide its core functionality.

Development Status

StreamTrigger is currently in active development. The application is being prepared for production use and TikTok integration review.
